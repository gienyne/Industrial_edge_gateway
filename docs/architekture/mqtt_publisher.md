# MQTT Publisher

## Purpose

The `MQTTPublisher` is responsible for all MQTT communication between the
Industrial Edge Gateway and the MQTT Broker.

It acts purely as a transport component.

The publisher does not know how Sparkplug messages are created and never
interprets their content.

---

## Responsibilities

The `MQTTPublisher`

- establishes the MQTT connection
- configures the MQTT Last Will
- publishes Sparkplug messages
- disconnects gracefully
- reports connection status

The publisher never

- reads sensors
- creates metrics
- encodes Sparkplug messages
- modifies application data

---

## Position in the Architecture

```text
DeviceData
      │
      ▼

SparkplugEncoder
      │
      ▼

SparkplugPayload
      │
      ▼

MQTTPublisher
      │
      ▼

MQTT Broker
```

The publisher transports already encoded Sparkplug messages without
interpreting their contents.

## Public Interface

```cpp
class IMqttPublisher
{
public:

    virtual ~IMqttPublisher() = default;

    virtual bool connect(const SparkplugPayload& willMessage) = 0;

    virtual void disconnect() = 0;

    virtual bool publish(const SparkplugPayload& payload) = 0;

    virtual bool isConnected() const = 0;
};
```

---

## MQTTPublisher

```cpp
class MQTTPublisher : public IMqttPublisher
{
public:

    explicit MQTTPublisher(Configuration& configuration);

    bool connect(const SparkplugPayload& willMessage) override;

    void disconnect() override;

    bool publish(const SparkplugPayload& payload) override;

    bool isConnected() const override;

private:

    Configuration& configuration_;

    bool connected_;

    void configureWill(const SparkplugPayload& willMessage);

    bool reconnect();
};
```

## Connection Lifecycle

The MQTT Last Will must be registered before the connection to the broker
is established.

```text
GatewayApplication
        │
        ▼

SparkplugEncoder
        │
encode(NDEATH)
        │
        ▼

SparkplugPayload (Last Will)
        │
        ▼

MQTTPublisher.connect()

        │
        ▼

MQTT Broker

        │
connection established

        │
        ▼

SparkplugEncoder
        │
encode(NBIRTH)
        │
        ▼

MQTTPublisher.publish()
```

The `GatewayApplication` coordinates this startup sequence.

The MQTT Last Will is generated by the `SparkplugEncoder` before the broker
connection is established.

The publisher registers this message during the MQTT connection process.

If the gateway disconnects unexpectedly, the broker automatically publishes
the configured `NDEATH` message.

---

## Publishing

The publisher receives a fully encoded `SparkplugPayload`.

```cpp
struct SparkplugPayload
{
    MqttTopic topic;
    BinaryPayload payload;
};
```

The publisher

- does not inspect the topic
- does not inspect the payload
- does not modify the message

It only transfers the provided data to the MQTT Broker.

---

## Design Principles

- Single Responsibility Principle
- Transport abstraction
- Dependency Injection
- Protocol-independent transport
- No hardware knowledge
- No application logic

## Future Extensions

Future versions may support

- automatic reconnect
- TLS encryption
- username/password authentication
- certificate-based authentication
- configurable QoS
- retained messages
- asynchronous publishing

The public interface remains unchanged.
